# Contributing

 

Thanks for contributing to this repository.

 

## How to contribute

- Keep changes focused and aligned with the repository structure and conventions in [docs/repository-conventions.md](docs/repository-conventions.md).

- Prefer small, reviewable changes.

- Update related documentation when behavior or paths change.

 

## Before submitting

- Check the relevant README and asset instructions.

- Validate the change with the smallest relevant check available.

- Review the final diff to confirm there are no unrelated edits.

 

## Pull requests

- Describe the change and why it is needed.

- Include any validation performed.

- At this point the administrators reserved the right to review and approve any contribution

- There is no time commitment to perform such of PR approval
